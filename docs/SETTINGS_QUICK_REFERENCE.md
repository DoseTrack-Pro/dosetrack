# Settings Quick Reference

Use this as a fast, one-page guide to what each Settings option does.

## Appearance
- **Theme (System / Light / Dark)**: Controls app color mode.

## Notifications
- **Dose reminders**: Turns scheduled "dose due" reminders on/off.
- **Low inventory**: Turns low-stock alerts on/off.
- **Missed dose**: Alerts on next app launch if a scheduled dose was missed yesterday.

## Privacy Lock
- **Require unlock**: Locks app behind PIN/biometric.
- **Use biometrics**: Lets fingerprint/Face Unlock open app (if supported).
- **Inactivity lock timer (Now / 1m / 5m / 15m)**: How long app can stay in background before locking.
- **Change PIN**: Updates your 4-digit app PIN.
- **Lock now**: Locks app immediately.

## NFC Scanning
- **Auto-log on scan**: Allows scan to log dose automatically.
- **Confirm before logging**: Forces confirmation before saving.
- **Scan timeout (10s / 20s / 30s)**: How long app waits for NFC tag/pen.

### NFC behavior combinations
- **Auto-log ON + Confirm OFF** -> fastest flow (auto-save possible).
- **Auto-log ON + Confirm ON** -> always asks before save.
- **Auto-log OFF** -> no auto-save behavior.

## Data & Export
- **Export as CSV**: Spreadsheet export.
- **Export as PDF**: Formatted report export.
- **Backup data (JSON)**: Save a `.json` backup file.
- **Restore from backup**: Replace current data with selected `.json` backup.

### Backup includes
- Compounds, dose logs, protocols, protocol links.

### Backup does NOT include
- App settings, app lock PIN, OS permissions.

## Danger Zone
- **Clear all data**: Permanently deletes all compounds/logs.

## Legal
- **Disclaimer**: Opens a read-only copy of the first-run legal disclaimer text.
- This is informational only and does not change your acceptance state.
